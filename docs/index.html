Automation With A Person In Charge

Every workflow that writes or sends something checks with a person or a rule first.

A person approves anything AI writes

Gemini drafts posts, broadcasts, metadata and report notes. Each draft waits in the Queue tab or an inbox until someone reviews it.

Test mode

While switched on, marketing emails go only to test subscribers.

Signed links

Every email link carries a signature, so a tampered link is rejected.

One suppression list

Every sending workflow checks it first, and an unsubscribe takes effect at once.

QA before every send

Emails with unfilled fields, missing unsubscribe links, spam-trigger wording or broken links are blocked and logged.

A daily send cap

Sending stops below the Gmail limit.

Facts kept apart from guesses

Reports label measured numbers and AI hypotheses separately.

No personal data in the code

Keys, IDs and addresses live in your own Google account, never in this repository.

One Control Sheet, Two Platforms

A single Google Sheet acts as the control centre for both versions. Its tabs hold the settings, subscribers, email events, enquiries, monitored sources, the claims register, an approval queue and a run log, so every action leaves a record the team can audit.

Google Apps Script

The script project bound to the sheet contains one short loader, pasted once. On each run it loads the current workflow code from this repository, so fixes and new workflows reach the sheet without anyone copying code. Scheduled jobs run every 10 minutes, every morning at 7 and every Monday at 8, and a Run tab starts any workflow on demand with a single tick box.

n8n

Each workflow is a standalone file in the n8n folder. Import it by URL and attach Google and Gemini credentials. The Config node at the start holds every setting, ready for your own values.

Public pages

The sign-up form, the enquiry form and the landing page behind every email link are hosted on GitHub Pages. Those pages pass requests to the workflows in the background, so a reader signed in to several Google accounts still lands on a working page.

Set It Up In An Afternoon

Google Apps Script

  1. Create a Google Sheet, then open Extensions and Apps Script.
  2. In Project Settings, tick Show "appsscript.json" manifest file in editor.
  3. Replace appsscript.json with apps-script/appsscript.json and Code.gs with apps-script/Loader.gs, then save.
  4. Deploy a web app: Deploy, New deployment, type Web app, execute as Me, access Anyone.
  5. Run cmaSetup from the editor and allow the permissions.
  6. In the Settings tab, add your web app URL and your Google Analytics property ID.
  7. Add your Gemini API key as the script property GEMINI_API_KEY.
  8. Point docs/assets/config.js at your web app URL and publish the docs folder with GitHub Pages.

n8n

  1. Import a workflow from the n8n folder.
  2. Add credentials for Google Sheets, Gmail, Google Analytics, Google OAuth2 with the Search Console scope, and an HTTP Header Auth credential for Gemini with the header x-goog-api-key.
  3. Replace the placeholders in the Config node and activate the workflow.
