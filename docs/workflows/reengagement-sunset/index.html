Run It Yourself

n8n

  1. In n8n, open Workflows, then Import from URL
  2. Paste https://raw.githubusercontent.com/archanacontent/content-marketing-automation-workflows/main/n8n/11-reengagement-sunset.json
  3. Fill in the Config node and connect the accounts listed above
  4. Activate the workflow
